# 🎮 MAZE QUIZ

> Game berbasis Unity yang menggabungkan eksplorasi maze dengan tantangan quiz interaktif.

## 📌 Deskripsi

**Maze Quiz** adalah game yang mengajak pemain untuk menjelajahi labirin (maze) sambil menyelesaikan berbagai pertanyaan (quiz). Untuk melanjutkan perjalanan, pemain harus menjawab soal dengan benar — menciptakan kombinasi antara gameplay eksplorasi dan edukasi.

## 🚀 Fitur Utama

* 🧭 Navigasi dalam maze (labirin)
* ❓ Sistem quiz interaktif
* 🎯 Progress berbasis jawaban pemain
* 🎮 Gameplay sederhana dan intuitif
* 🔊 (Opsional) Audio & efek visual Unity

## 🛠️ Teknologi

* **Engine**: Unity
* **Bahasa**: C#
* **Version Control**: Git & GitHub

## 📂 Struktur Project

```
Assets/             # Semua asset game (scene, script, prefab, dll)
Packages/           # Dependencies Unity
ProjectSettings/    # Konfigurasi project
```

## ⚙️ Cara Menjalankan Project

1. Clone repository:

   ```bash
   git clone https://github.com/MAZE-QUIZ/Project.git
   ```
2. Buka Unity Hub
3. Klik **Open Project**
4. Pilih folder project ini
5. Jalankan scene dari Unity Editor
